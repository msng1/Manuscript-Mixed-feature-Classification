# Yoga-MFET-Classification

**Text-Based Yoga Asana Classification Using Mixed Feature Extraction**

This repository contains a research implementation that classifies yoga asana text images through an image-to-text pipeline.

## Method

4. **Classification:** an RBF-kernel Random forest predicts the asana class.

> Important: The classifier receives generated text features, not raw image pixels. Inspect `generated\\\_image\\\_descriptions` before interpreting performance.

## Dataset structure

Place your own dataset locally in this structure:

```text
DATASET\_Manuscript/
├── Bhdrasana/
│   ├── image001.jpg
│   └── image002.jpg
├── Matasyanasana/
│   ├── image001.jpg
│   └── image002.jpg
└── Kukkutasana/
    ├── image001.jpg
    └── image002.jpg
```

Each class folder name is used as its label. Supported image extensions: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.webp`.

## Installation

Python 3.10 or 3.11 is recommended.

```bash
git clone https://github.com/YOUR-USERNAME/Yoga-MFET-Classification.git
cd Yoga-MFET-Classification
python -m venv .venv
```

Activate the environment:

**Windows**

```bash
.venv\\\\Scripts\\\\activate
```

**macOS/Linux**

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

 Internet access is required for the first download. A CUDA-enabled GPU is used automatically when available; CPU execution is also supported but may be slower.

## Train and evaluate

```bash
python yoga\\\_mfet.py --data\\\_dir Yoga\\\_Dataset --output\\\_dir results
```

Optional settings:

```bash
python yoga\\\_mfet.py --data\\\_dir Yoga\\\_Dataset --output\\\_dir results --test\\\_size 0.2 --seed 42
```

## Predict a new image

After training:

```bash
python yoga\\\_mfet.py --predict path/to/new\\\_yoga\\\_image.jpg --model\\\_dir results/model
```

The script prints the generated caption, predicted class and SVM class probabilities.

## Output files

The `results/` directory contains:

* `classification\\\_report.txt` — per-class precision, recall and F1-score.
* `metrics.json` — accuracy and macro-averaged metrics.
* `confusion\\\_matrix.png` — confusion matrix.
* `model/yoga\\\_mfet\\\_model.joblib` — trained classifier and fitted vectorizers.

Results are generated by running the experiment; no performance values are claimed in advance.

## Evaluation and research cautions

* Use enough images per class. At least two are needed by the script for a stratified split, but substantially more are recommended.
* Check for duplicate and near-duplicate images before splitting. If multiple images come from the same person, video, session or source, use a group-wise split so related images cannot appear in both training and test sets.
* The random stratified split in this baseline is image-level. It does not automatically detect duplicate images or group images by subject/session.
* Report the exact dataset, split strategy, pretrained model versions and settings in any paper.
